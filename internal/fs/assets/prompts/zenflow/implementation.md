# Zenflow Step Guide: Implementation

Цель этапа: реализовать изменения строго по утвержденной спецификации.

Обязательно:
1. Прочитать `.spec_agent/prompts/spec_rules.md`.
2. Прочитать `.spec_agent/prompts/workflow.md`.
3. Внести изменения в код в рамках согласованного scope.
4. Если меняется поведение — сначала обновить соответствующие спецификации рядом с кодом.
5. Заполнить `{@artifacts_path}/report.md` результатами реализации.

`report.md` должен содержать:
- что изменено в коде;
- какие спецификации обновлены;
- какие проверки/тесты выполнены;
- ограничения, риски, долги.

Критерий готовности:
- код и спецификации синхронизированы, report заполнен.
