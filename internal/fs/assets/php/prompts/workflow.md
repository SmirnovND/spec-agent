# Жизненный цикл работы агента (PHP)

## 1. Получение задачи
- Определить entry-point (controller/command/job/listener).

## 2. Анализ
- Прочитать entry spec и связанные ссылки.
- Определить scope изменений.

## 3. Планирование
- Создать change-plan в `spec_changes/YYYYMMDD_HHMM_description.md`.

## 4. Реализация
- Сначала изменить спецификацию, затем код.

## 5. Завершение
- Проверить синхронность code/spec и закрыть чек-лист.
