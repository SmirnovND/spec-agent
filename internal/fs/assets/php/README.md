# PHP Profile Assets

Ресурсы для работы spec-agent в PHP-проектах.

Содержимое:
- `prompts/spec_rules.md` — правила спецификаций для PHP-слоя
- `prompts/agent_prompt.md` — базовые инструкции агенту для PHP
- `prompts/workflow.md` — жизненный цикл изменений
- `prompts/zenflow/*.md` — этапные инструкции для Zenflow workflow
- `examples/` — примеры PHP-спецификаций
