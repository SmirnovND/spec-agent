# Zenflow Step Guide: Implementation

Цель этапа: реализовать изменения строго по утвержденной спецификации.

Обязательно:
1. Следовать правилам текущего этапа.
2. Внести изменения в код в рамках согласованного scope.
3. Если меняется поведение — сначала обновить соответствующие спецификации рядом с кодом.
4. Заполнить `{@artifacts_path}/report.md` результатами реализации.

`report.md` должен содержать:
- что изменено в коде;
- какие спецификации обновлены;
- какие проверки/тесты выполнены;
- ограничения, риски, долги.

Критерий готовности:
- код и спецификации синхронизированы, report заполнен.
